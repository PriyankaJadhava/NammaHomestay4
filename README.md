# Namma HomeStay

A modern Android application for managing homestay services, menus, guest inquiries, and local travel guidance.

## Features

- Secure Login System
- Verification Checklist
- Food Menu Management
- Guest Inquiry Box
- Secret Tourist Spots Guide
- Dark Theme Modern UI

## Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose / XML
- Material Design
